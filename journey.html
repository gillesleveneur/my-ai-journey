Day 1 — From a local file to the web

I started with a simple HTML page on my computer. I learned how HTML, CSS, Git and GitHub work together.

What I learned

  • HTML structures a webpage.
  • CSS controls its appearance.
  • Git keeps track of changes.
  • GitHub stores and shares the project.
  • GitHub Pages publishes the website.

What surprised me

The interesting part is not the technology itself, but understanding how the different pieces connect.
